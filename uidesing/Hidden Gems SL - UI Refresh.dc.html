Design review · Hidden Gems SL

UI refresh: sharper hierarchy, calmer surfaces, same brand DNA

I pulled the live theme (AppTheme, OracleUI) and six core screens straight from the repo — Onboarding, Login, Home, Discovery, Place Details and the Trip Planner — and rebuilt them below exactly as they ship today (left, labelled CURRENT), so we're grounded in the real thing, not a guess.

Next to each is a refreshed pass (REFRESH) that keeps the terracotta/ochre palette, Outfit + Inter type, and the app's "Oracle" voice — but fixes what's working against it: ALL-CAPS overload, competing glass borders on every surface, low-contrast small type, and cluttered card chrome. The refresh leans into bigger imagery, quieter surfaces, one confident accent per screen, and clearer type scale.
